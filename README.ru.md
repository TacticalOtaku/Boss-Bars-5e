# Boss Bars 5e

**Полосы боссов и карточки элитных противников в стиле RPG для Foundry VTT (D&D 5e)**

Отрисовка на шейдерах WebGL2, многофазные бои, настраиваемые облики, реплики боссов, музыкальное сопровождение и индивидуальное размещение на экране — без раскрытия игрокам точных цифр ХП.

## Установка

Вставьте **URL манифеста** в окно установки модулей Foundry VTT (**Дополнительные модули → Установить модуль → Manifest URL**):

```text
https://github.com/TacticalOtaku/Boss-Bars-5e/releases/latest/download/module.json
```

**Требования:** Foundry VTT **14** (проверено на `14.367`), D&D 5e **`5.3.3+`**. **Midi QOL 14** поддерживается опционально и не является обязательным.  
**Ручная установка:** скачайте `boss-bars-5e-v<версия>.zip` со страницы [GitHub Releases](https://github.com/TacticalOtaku/Boss-Bars-5e/releases/latest) и распакуйте в `Data/modules/boss-bars-5e`.

## Быстрый старт

Босс получает крупную полосу поверх сцены с портретом, именем, титулом, заливкой ХП с затухающим следом урона, фазами, репликами, музыкой и собственным визуальным обликом. Менее значимые сильные враги выводятся компактными карточками в колонке элиты, отсортированной по рангам. Игроки видят степень ранения противника, но никогда не видят точные значения ХП.

1. Нажмите правой кнопкой мыши по иконке **черепа** в HUD токена (или выберите **Профиль Boss Bars** в меню `⋮` листа актёра) и настройте профиль: **Босс** или **Элита**, имя для игроков, портрет и режим показа — **На каждый токен** или **Одна на актёра**.
2. Нажмите на кнопку **черепа**, чтобы показать или скрыть полосу. Кнопка **Boss Bars** на панели инструментов токенов открывает **Хаб** — единое окно для активных полос на сцене, всех профилей, рангов элиты и библиотеки обликов.
3. Начинайте бой. Заполнение полосы отслеживает ХП напрямую из данных актёра независимо от способа изменения.

Изменять полосы могут только мастера (GM); если подключено несколько GM, изменения записывает активный мастер.

## Возможности

- **Полосы боссов:** заливка ХП с затухающим следом полученного урона, щит временного ХП, баннер/эффект поражения и возможность для игрока свернуть полосу. Несколько боссов аккуратно выстраиваются друг над другом.
- **Хаб Boss Bars:** одно окно для GM со всем необходимым — **На сцене** (показ, скрытие, фазы, счётчики, реплики, локальные настройки HUD), **Профили** (поиск, перетаскивание актёра или привязка выделенного токена), **Ранги элиты** и **Библиотека обликов** (предупреждает перед сбросом несохранённых правок).
- **Колонка элиты:** карточки, отсортированные по рангу (название, цвет, размер иконки и видимые элементы настраиваются в разделе **Ранги элиты**), режим **На каждый токен** с нумерацией или **Одна на актёра** с множителем `×N`, а также счётчик переполнения `+N`.
- **Статусы:** иконки эффектов токена с подсказками; служебные эффекты Midi QOL и дубликаты DAE автоматически отфильтровываются. Лишние эффекты можно скрыть по названию, а пользовательские статусы босса — переключать в Хабе.
- **Мини-полосы:** до 6 штук на полосу босса или карточку элиты — временное ХП, легендарные действия и сопротивления, заряды предметов, любой путь `system.` или ручной счётчик. Каждую мини-полосу можно скрыть от игроков отдельно.
- **Автопоказ:** автоматическое появление при достижении 1-го раунда боя и скрытие при завершении боя или поражении через заданную задержку.
- **Персональная раскладка HUD:** каждый игрок и GM могут перетаскивать отдельные полосы боссов или двигать колонку элиты целиком. Позиции автоматически сохраняются отдельно для каждого клиента и сцены между перезагрузками. Управление с клавиатуры: фокус через `Tab`, перемещение стрелками (`Shift` для шага `10 px`), `Home` для сброса, `Esc` для отмены перетаскивания.
- **Движок обликов WebGL2:** 17 встроенных обликов (рамка, заливка, имя, эффекты, статусы, дополнительные элементы, анимации, компоновка), 9 макетов полос и 4 макета карточек (`S`–`XL`), а также 30 встроенных шрифтов с поддержкой латиницы и кириллицы. Отрисовывается через общий WebGL2-шейдер с подсвеченными материалами (`liquid`, `energy`, `flame`, `ice`, `void`, `gradient`), резными узорами, парящими искрами и эффектами удара/лечения/смены фазы/поражения/появления (при отсутствии WebGL2 автоматически переходит на CSS и 2D-искры). Библиотека обликов позволяет копировать, редактировать, импортировать и экспортировать облики и пресеты с живым превью.
- **Фазы:** до 6 фаз, срабатывающих в начале боя, при снижении ХП ниже порога, при смене формы (переносе полосы на токен другого актёра) или вручную. Каждая фаза может переопределять имя, титул, портрет, облик и музыку с эффектом перехода, отображая либо общее ХП с отметками порогов, либо полное заполнение заново для каждой фазы.
- **Фразы:** реплики над полосой по 11 триггерам — появление полосы, вход в фазу, ХП ниже порога, сильный удар, лечение, начало хода, добавление статуса, критическое попадание, промах, поражение или ручной запуск. Поддерживаются наборы фраз, случайный/последовательный порядок, кулдауны, однократность за бой, приоритеты и быстрые реплики прямо из Хаба.
- **Музыка:** отдельный трек или плейлист для каждого босса и каждой фазы; игравшая до этого музыка плавно затухает и возобновляется с прежнего места после боя.
- **Щадящая анимация:** учитывает системную настройку `prefers-reduced-motion` и режим низкой производительности Foundry, отключая тряску, частицы и анимированные заливки.

## Полезно знать

- **Приватность в консоли:** игроки не видят в интерфейсе цифры ХП врагов, списки фаз или ещё не произнесённые реплики, однако данные и флаги актёра синхронизируются на клиент, поэтому технически подкованный игрок может прочитать сырые данные через консоль браузера.
- **Реплики при крите и промахе:** триггеры критического попадания и промаха срабатывают только в том случае, если атакующий взял босса в цель до броска.
- **Область действия музыки:** музыка переключается только на сцене, которая в данный момент активна для игроков.

## Разработка

Требуется **Node.js 24+** (`npm ci`). GitHub Actions ([ci.yml](.github/workflows/ci.yml)) проверяет коммиты в `main` на Node.js 24 и 26; релизы по тегам `v*` собирают и публикуют ZIP-архив и `module.json` через [release.yml](.github/workflows/release.yml).

```bash
npm ci               # Установка зависимостей
npm run check        # Проверка типов, ESLint, Stylelint, Prettier, Vitest, сборка Vite и контроль размера HUD
npm run stand        # Запуск локального стенда предпросмотра на Vite
npm run deploy       # Деплой собранного модуля в Foundry Data/modules/boss-bars-5e
npm run package      # Упаковка dist/boss-bars-5e-v<версия>.zip из dist/module
npm run release      # Выполнение check + package
```
