# Fonts

All fonts are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). The files are the
`latin` and `cyrillic` subsets served by Fontsource (https://fontsource.org), a mirror of Google Fonts.

The files are unmodified. Each font's copyright notice and the full license text are in its `OFL-*.txt`, taken from
https://github.com/google/fonts.

| File stem | Font | License | Source |
|---|---|---|---|
| `cormorant-*` | Cormorant (variable, 300–700) | `OFL-cormorant.txt` | https://fonts.google.com/specimen/Cormorant |
| `philosopher-*` | Philosopher (400, 700) | `OFL-philosopher.txt` | https://fonts.google.com/specimen/Philosopher |
| `russo-one-*` | Russo One (400) | `OFL-russo-one.txt` | https://fonts.google.com/specimen/Russo+One |

Boss Bars 5e registers them lazily: a file is downloaded only when text in that font and subset is shown.
