# Fonts

All fonts are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). The files are the
`latin` and `cyrillic` subsets served by Fontsource (https://fontsource.org), a mirror of Google Fonts.

| File stem | Font | Source |
|---|---|---|
| `cormorant-*` | Cormorant (variable, 300–700) | https://fonts.google.com/specimen/Cormorant |
| `philosopher-*` | Philosopher (400, 700) | https://fonts.google.com/specimen/Philosopher |
| `russo-one-*` | Russo One (400) | https://fonts.google.com/specimen/Russo+One |

Boss Bars 5e registers them lazily: a file is downloaded only when text in that font and subset is shown.
