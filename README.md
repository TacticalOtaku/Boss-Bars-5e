# Boss Bars 5e

RPG boss bars and elite cards for important enemies in Foundry VTT (D&D 5e).

**Status: early development.** Version 0.1.0 is the build skeleton: the module loads and adds an empty overlay,
nothing is drawn yet.

- Foundry VTT 14 (verified 14.367), dnd5e 5.3.3.
- Languages: English, Russian.
