# Без UI-фреймворка и анимационных библиотек, один общий WebGL2-контекст

> Частично заменено [ADR 0003](0003-shader-drawn-bars-and-cards.md): шейдер рисует тела всех полос босса, плашки карточек элиты и рамки портретов, а не только пять «живых» заливок.

HUD — свой небольшой рендерер на чистом DOM. Редакторы — ApplicationV2 с шаблонами Handlebars, анимации — Web Animations API и CSS. React и GSAP не используются: старый `boss-bar` на React и GSAP дал основной чанк 840 кБ, а приватная копия GSAP потребовала переписывать её исходник при сборке. У игрока бюджет HUD ~100 кБ gzip. Заливка рисуется на CSS и SVG. «Живые» заливки полос босса (жидкость, энергия, пламя, лёд, пустота) рисует **один** общий WebGL2-контекст: кадр рендерится вне экрана и копируется в canvas полосы. Canvas на каждую полосу упирается в лимит браузера, примерно 16 живых контекстов на вкладку, причём один уже занят холстом Foundry. Карточки элиты всегда на CSS. Без WebGL2 полоса показывает CSS-вариант той же палитры. Частицы — один общий 2D-canvas поверх HUD, он существует, только пока живы частицы.
