# План этапа 8 — музыка

Дата: 2026-10-26 · Статус: **одобрен**
Спека: [§8 «Музыка босса»](../spec.md#8-музыка-босса), §2 (снимок — скрытая мировая настройка), §11,
[§16 строка 8](../spec.md#16-этапы).
Тикет: [#14 Музыка босса](https://github.com/TacticalOtaku/Boss-Bars-5e/issues/14) (решение 2026-10-25: источник,
снимок и пауза, приоритет, фазы, конец, ручные действия ГМа, активная сцена, ловушка с `fade`).
Макет: `prototype/editors`, вкладка «Музыка» (трек или плейлист, приоритет, переход в мс).

## Результат (версия 0.9.0)

- **Музыка босса**: трек или плейлист на босса и, по желанию, на фазу; приоритет; длительность перехода (2 с).
- **Начало**: первый показанный босс с музыкой — то, что играло, затухает и запоминается, стартует музыка босса.
- **Несколько боссов**: играет музыка ведущего (приоритет, затем размер, затем порядок показа); смена ведущего —
  плавный переход.
- **Фазы**: фаза со своей музыкой — переход на неё; без музыки — ничего не меняется; форма тоже фаза.
- **Конец**: ушёл последний босс с музыкой — его музыка затухает, прежняя продолжается с места паузы.
- **Ручные действия ГМа** не перебиваются: модуль трогает только то, что сам запустил или сам остановил.
- **Вкладка «Музыка»** в профиле и музыка во «При входе» у фазы.

Не входит в этап: API музыки (этап 11); победный мотив (тикет: нет).

## Факты Foundry 14.367 (исходники)

- Играет поле `playing` у Playlist и PlaylistSound; писать его может ГМ, звук включается у всех клиентов.
- Пауза в ядре — `{ playing: false, pausedTime: currentTime }` (`playlist-directory.mjs:683`), и `PlaylistSound#sync`
  останавливает такой звук **без затухания** (`playlist-sound.mjs:145`). Затухание при остановке есть только без
  `pausedTime`; его длину задаёт `fade` трека или плейлиста (`fadeDuration`).
- Старт с места: `pausedTime` при `playing: true` становится смещением (`playlist-sound.mjs:172`), затухание входа —
  тот же `fadeDuration`.
- Плейлист в своём режиме: `Playlist#playAll` (последовательный, случайный, одновременный), трек — `playSound`.

## Данные

**Профиль босса** (необязательные поля, читатель нормализует):
- `music: { type: "sound", playlistId, soundId } | { type: "playlist", playlistId } | null`;
- `musicPriority` (целое, по умолчанию 0), `musicFade` (мс, по умолчанию 2000);
- у фазы `enter.music` — источник; нет — музыка не меняется.

**Снимок** — скрытая мировая настройка `music` (своя версия `MUSIC_VERSION = 1`):
- `paused: [{ playlistId, soundId, time, fade }]` — что модуль остановил и с какого места продолжит;
- `started: [{ playlistId, soundId, fade }]` и `source` — что модуль запустил сейчас;
- `fades` — исходные `fade` треков, которые модуль временно поменял (вернуть даже после F5 или падения).

**Версии:** `PROFILE_VERSION` остаётся 2 (читатель 0.8.0 сохраняет неизвестные ключи); новая настройка — `MUSIC_VERSION` 1.

## Поведение

### Ведущий босс (`core/music.ts`, чистый)

- Кандидаты — показанные боссы **активной** сцены с музыкой: не повержены, токен не скрыт.
- Музыка босса — последняя музыка фаз от первой до показанной фазы, иначе музыка профиля.
- Ведущий: наибольший приоритет, затем размер, затем порядок показа. Ответ — источник и длительность перехода, или
  «музыки нет».

### Переходы (только активный ГМ, `foundry/music.ts`)

- После каждого пересчёта и при смене активной сцены ГМ сравнивает нужный источник с тем, что в снимке.
- **Начало** (снимка нет, источник есть): все играющие треки записываются в снимок с местом и исходным `fade`,
  останавливаются с затуханием (временный `fade` = длительность перехода, без `pausedTime`); музыка босса стартует с
  тем же временным `fade`. Через длительность перехода исходные `fade` возвращаются.
- **Смена источника** (другой ведущий или фаза с музыкой): свои треки затухают, новые стартуют. Тот же источник —
  ничего.
- **Конец** (источника нет): свои треки, которые ещё играют, затухают; треки снимка, которые всё ещё стоят на его
  остановке (`playing: false`), продолжаются с места; снимок очищается.
- **Ручные действия ГМа:** запущенный ГМом трек модуль не останавливает; остановленную ГМом музыку босса не
  перезапускает, пока не сменится источник; трек снимка, который ГМ сам включил посреди боя, в конце не трогает.
- Без ГМа в сети музыка не меняется. После загрузки активный ГМ сверяет снимок: возвращает зависшие `fade` и, если
  босса с музыкой уже нет, завершает.

## Окна

- **Профиль босса → «Музыка»**: источник (список плейлистов с их треками: «весь плейлист» или трек), приоритет,
  длительность перехода в секундах.
- **«Фазы» → «При входе»**: музыка («как раньше» или источник).

## Живая проверка (мир `test`, ГМ + игрок)

1. Фон ошибок; босс без музыки ничего не трогает.
2. Играет трек мира → показан босс с музыкой: трек затухает, музыка босса стартует (у игрока тоже).
3. Второй босс с большим приоритетом → переход; скрыли его → переход обратно.
4. Фаза с музыкой → переход; фаза без музыки → без изменений.
5. Скрыли последнего босса (и отдельно — поражение) → музыка босса затухает, прежний трек продолжается с места.
6. ГМ вручную включил трек посреди боя → модуль его не трогает; ГМ остановил музыку босса → модуль её не
   перезапускает.
7. F5 ГМа посреди перехода → `fade` треков вернулись к исходным.
8. Смена активной сцены → музыка завершается.
9. Вкладка «Музыка», музыка фазы; регрессия этапов 1–7.

## Решения (2026-10-26, «Всё да»)

1. Один заход без остановки, коммит один в конце.
2. Длительность перехода — временным `fade` у треков, которые модуль гасит или запускает; исходные значения в снимке,
   возвращаются после перехода и после F5 или падения.
3. Прежняя музыка останавливается с затуханием, место паузы модуль хранит сам и продолжает с него; на время боя трек
   выглядит остановленным.
4. Босс со скрытым токеном музыку не включает.
5. Повержённый босс перестаёт вести музыку сразу.
6. Музыка фаз копится сверткой; ждущая форма звучит как фаза перед ней; тот же источник — без перехода.
7. Приоритет 0–100 (0), переход 0–10 с (2); профиль остаётся v2, снимок — скрытая настройка `music` v1.
8. Ручные действия ГМа не перебиваются (как в «Поведении»).
9. Смена активной сцены на сцену без босса с музыкой завершает музыку; просматриваемая сцена не влияет.
10. Живая проверка на временном плейлисте «Boss Bars QA» из звуков ядра; после проверки он удаляется.
