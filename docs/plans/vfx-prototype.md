# Прототип VFX обликов (ветка `prototype/vfx`)

Дата: 2026-10-26 · Статус: **одобрен** («Всё да»), прототип.
Цель: облики и эффекты уровня экшен-игр (Diablo IV, Lost Ark, Hades) вместо плоских CSS-полос. Ветка orphan: после
одобрения код переносится в `main` (ADR 0003, частично заменяет ADR 0002), каталог из 30 обликов переделывается.

## Почему сейчас дёшево

1. Всё обрезано прямоугольником полосы: свечение, языки пламени, искры не выходят за край.
2. Заливки — плоский шум с палитрой: нет фаски, бликов, внутренней тени, мениска на границе ХП.
3. Эффекты — полупрозрачная вспышка, сдвиг по X и одна SVG-трещина, растянутая на всю полосу.
4. Рамки, портреты, карточки — CSS-рамки без металла, гравировки, отблеска.

## Решения

1. Ориентир — насыщенный экшен-VFX; спокойные облики сдержаннее.
2. Тело полосы (рамка, материал, свечение, эффекты, частицы) рисует общий WebGL2-рендерер, один контекст. Текст,
   портрет, статусы, мини-полосы — DOM поверх.
3. Прототип на стенде: «Классика», «Пепел и пламя», «Вечная мерзлота»; урон, крупный удар, лечение, фаза, поражение,
   появление.
4. Бюджет: цель 60 fps; видимые полосы боссов в покое ~30 fps, карточки ~15 fps или неподвижны; уменьшенное движение —
   один неподвижный кадр.
5. Канвас больше полосы на запас по краям: эффекты выходят за полосу, клики не перехватываются.
6. Сохранённые облики читаются; новые параметры со значениями по умолчанию; 30 встроенных перерисовываются.
7. Графика процедурная: SDF, шум, освещение в шейдерах; без скачанных текстур.
8. Порядок: полоса босса → карточки элиты → портреты, текст, статусы, мини-полосы. Выпуск 1.1.0.
9. Тесты только на согласованных швах: таймлайн эффектов (`core/look/vfx.ts`), облик → параметры шейдера,
   частицы, планировщик кадров, чтение схемы. Качество картинки — глазами (стенд, записи кадров, одобрение).
10. Мир `test` без разрешения не трогается; прототип проверяется на стенде в Chrome.

## Отзыв на прототип (2026-10-26)

- Огонь выглядит странно: переделать. Остальное ближе к цели, качество можно поднять ещё.
- Каталог может отойти от «30 в каждой категории»: несуразные компоновки и облики убрать или объединить ради общего
  качества.

## Доводка и хвосты (2026-10-26)

- Облики доведены четвёрками. Новые параметры заливки: `pattern` (руны, чешуя, дамаск, чернила) и `motes` (светлячки,
  угольки, блёстки); «Сталь и кровь» — жидкость, «Пергамент» — чернила на бумаге с рваным краем.
- Эффекты удара и фазы слушаются облика: `hpEffect.sparks` / `damageFlash` / `bigCrack` → `u_hit`, `motion.phaseFlash` /
  `phaseCrack` → `u_phase`. Спокойный облик на смене фазы даёт мягкую волну своего света без белой вспышки и столбов.
- Иконки карточек: плашка рисует кольцо в форме портрета облика снаружи иконки (кроме компоновки «плитка»).
- Огонь и угольки гаснут за названием и титулом босса (их рамка уходит в шейдер), под текстом ложится дым.
- Уменьшенное движение на карточках: неподвижный кадр, перерисовка только при изменении.
- 12 карточек + босс (RTX 5070, DPR 2): 165 fps в покое, 152–164 под ударами. При CPU ×4 до атласа 132 / 62 / 43 fps
  (покой / удары по элите / удары по боссу и элите), после — 156 / 109 / 58. Атлас: все цели кадра рисуются в
  полосы общего GL-канваса и копируются после, иначе браузер снимал буфер на каждую копию (`drawImage` — треть
  кадра). Кнопка стенда «12 элит» заполняет колонку.
