# План этапа 9 — живые заливки и частицы

Дата: 2026-10-26 · Статус: **одобрен**
Спека: [§12 «Стек, рендер, производительность»](../spec.md#12-стек-рендер-производительность), §9 (заливка: живые
типы; эффект ХП: искры), [§16 строка 9](../spec.md#16-этапы).
Решения: [ADR 0002](../adr/0002-no-ui-framework-one-shared-webgl.md),
[#10 Стек и рендер](https://github.com/TacticalOtaku/Boss-Bars-5e/issues/10) (один общий WebGL2-контекст, кадр вне
экрана копируется в canvas полосы; частицы — один общий 2D-canvas, пока живы; ловушки `u_time` и потери контекста).

## Результат (версия 0.10.0)

- **Живые заливки полосы босса** — жидкость, энергия, пламя, лёд, пустота — рисует **один** WebGL2-контекст на всю
  страницу. Кадр рендерится вне экрана и копируется в 2D-canvas каждой полосы (2D-контексты не упираются в лимит
  ~16 WebGL-контекстов, один из которых занят холстом Foundry).
- **Запасной путь**: без WebGL2 или после потери контекста полоса показывает нынешний CSS-вариант той же палитры.
- **Частицы**: один общий 2D-canvas поверх HUD, пул с потолком; искры при уроне и пепел при уходе «распад».
- Карточки элиты всегда на CSS; уменьшенное движение — без частиц и без движения заливки.

Не входит в этап: значения 30 тем (этап 10), полная проверка бюджета 60 fps (этап 11).

## Поведение

### Живая заливка

- Полоса с живым типом заливки получает `<canvas>` во весь meter. Пока canvas рисует, CSS-заливка под ним скрыта;
  след урона, щит, засечки и эффекты остаются на CSS поверх.
- Шейдер рисует и саму долю ХП: `u_fill` плавно догоняет новую долю в цикле кадров (вместо `scaleX` CSS-заливки).
- Пять своих фрагментных шейдеров GLSL ES 3.0 (строки в TS, без плагинов сборки) на палитре `fill.colors` (2–5 цветов)
  и `u_time` по модулю периода (ловушка fp16). Без текстур.
- **Цикл кадров** общий: ~15 fps в покое; ~60 fps, пока доля догоняет новую (около 0,6 с). Нет видимых живых полос —
  цикла нет.
- **Не рисуется** скрытое: свёрнутая полоса, уходящая, вкладка в фоне, полоса без размеров.
- **Потеря контекста**: canvas прячется, CSS-заливка возвращается сразу; на `webglcontextrestored` шейдеры
  собираются заново. Не удалось создать контекст при старте — CSS до конца сессии.
- Превью в окнах ГМа (мастерская, библиотека, профиль) рисуют тот же рендерер и тот же контекст.

### Частицы

- Общий 2D-canvas создаётся на первую частицу и удаляется, когда последняя гаснет; пул — не больше 200 частиц.
- **Искры** при уроне — из края заливки, число по доле урона; новые параметры эффекта ХП «искры» и «цвет искр».
- **Пепел** при уходе с поражением «распад» — из прямоугольника полосы.
- Уменьшенное движение: частиц нет.


## Живая проверка (мир `test`, ГМ + игрок)

1. Фон ошибок; заливки «сплошная», «градиент», «текстура» как в 0.9.0.
2. Пять живых типов на полосе босса (облик «Вечная мерзлота» — лёд, «Неон» — энергия, остальные через библиотеку).
3. Урон и лечение: доля догоняет плавно, след урона на месте; искры при уроне; пепел при «распаде».
4. Потеря контекста (`WEBGL_lose_context`) — CSS-заливка сразу, восстановление — снова живая.
5. Свёрнутая полоса и фоновая вкладка не рисуются (цикл стоит).
6. Уменьшенное движение: заливка стоит, частиц нет.
7. Счётчик WebGL-контекстов: один на модуль при двух боссах и открытой мастерской.
8. Грубый замер fps: 2 живые полосы + 12 карточек элиты.
9. Регрессия этапов 1–8.

## Решения (2026-10-26, «Всё да»)

1. Два захода с остановкой: сначала рендерер, шейдеры, запасной путь, потеря контекста и стенд; затем частицы,
   параметры облика, живая проверка и замер fps. Коммит один, в конце.
2. Шейдер рисует долю ХП (догоняет в кадре); CSS-заливка под canvas скрыта, пока он рисует; след, щит, засечки и
   эффекты — CSS поверх.
3. ~15 fps в покое, ~60 fps около 0,6 с после изменения; без видимых живых полос цикла нет.
4. Только полосы босса, включая превью окон ГМа (тот же контекст); элита — CSS; свёрнутое, уходящее и фоновая вкладка
   не рисуются.
5. Уменьшенное движение: один неподвижный кадр, перерисовка только при изменении.
6. Потеря контекста: CSS сразу, на восстановлении шейдеры заново; не создался при старте — CSS до конца сессии.
7. Частицы: искры при уроне (параметры «искры», «цвет искр», число по доле урона), пепел при «распаде»; пул ≤ 200;
   раскол рамки остаётся CSS.
8. Пять своих шейдеров на палитре `fill.colors`, без текстур, строками в TS; `u_time` по модулю периода.
9. Встроенные: Классика — золотые искры; Мерзлота — живой лёд, ледяные искры; Неон — живая энергия, пурпурные искры.
   Версия библиотеки не меняется.
10. Грубый замер fps в браузере пилота (2 живые полосы + 12 карточек); полный бюджет — этап 11.
