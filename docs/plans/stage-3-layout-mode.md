# План этапа 3 — режим раскладки

Дата: 2026-10-26 · Статус: **одобрен пользователем 2026-10-26** («Всё да»)
Спека: [§2, §10, §16 строка 3](../spec.md#16-этапы). Тикет: [#11 Режим раскладки](https://github.com/TacticalOtaku/Boss-Bars-5e/issues/11).
Макет: `prototype/layout-mode` (вариант A — свободное перетаскивание). Факты: `research/foundry-ui` §1–3.

## Результат (версия 0.4.0)

- ГМ включает режим раскладки из панели «Активные боссы».
- На своём экране ГМ тащит «стек боссов» и «колонку элиты». Блок прилипает к центру и краям. При отпускании он
  цепляется к ближайшему из 9 якорей (по третям экрана), и отступ пересчитывается от этого якоря.
- Плавающая панель «Раскладка» задаёт для каждого блока:
  - отступ X и Y числами;
  - направление;
  - сколько карточек элиты видно;
  - «Игроки могут сворачивать».
- Слои «Мир» и «Сцена». На слое сцены тронутый блок целиком переопределяется флагом сцены, рядом стоит кнопка
  «Сбросить к миру».
- Перекрытия блоков с интерфейсом Foundry и выход за край экрана подсвечиваются. Сам модуль ничего не сдвигает.
- Есть предпросмотр экрана игрока от 1366×768 до 3440×1440.
- Игрок видит блоки там, куда их поставил ГМ, у тех же якорей на любом разрешении. Он может только свернуть блок,
  если ГМ разрешил.

## Данные

**Раскладка** — мировая настройка `layout` (v1). Сцена переопределяет блок целиком флагом
`scene.flags.boss-bars-5e.layout` (v1, только тронутые блоки).

```ts
type Anchor = "tl" | "tc" | "tr" | "ml" | "mc" | "mr" | "bl" | "bc" | "br";
interface Block { anchor: Anchor; dx: number; dy: number; dir: "down" | "up" | "row"; collapse: boolean }
interface Layout { dataVersion: 1; bosses: Block; elites: Block & { max: number } }
```

- `dx` и `dy` хранятся в px при `uiScale = 1`. На экране они умножаются на `uiScale` клиента.
- Направление `row` бывает только у боссов, `max` — от 1 до 20.
- Значения по умолчанию совпадают с нынешними:
  - боссы — `tc`, 0, 16, вниз;
  - элита — `ml`, 104, 0, вниз, 12 карточек;
  - «сворачивать» включено у обоих.
- Мировая настройка «Игроки могут сворачивать» уходит из настроек модуля. Её значение один раз переносится в блок
  боссов.

## Как блок встаёт на экран

Только CSS, без замеров:

```
left: calc(fx·100% + dx·uiScale)   top: calc(fy·100% + dy·uiScale)   translate: −fx·100% −fy·100%
```

`fx` и `fy` — доли якоря (0, ½, 1). Блок выравнивается той же точкой, что и якорь, поэтому у игрока на
1366×768 и на 2560×1440 он стоит у того же якоря. Смена разрешения, док камер и `uiScale` не требуют пересчёта.
`ResizeObserver` на `#interface` нужен только в режиме раскладки, для подсветки перекрытий.

## Ядро (`core/layout.ts`, чистые функции с тестами)

- `readLayout(world, sceneOverride)` — разбор, значения по умолчанию, слияние слоёв поблочно.
- `toAnchor(rect, screen, uiScale)` — якорь по третям экрана (по центру блока) и отступ от него.
- `snap(rect, screen)` — прилипание к центру и краям в пределах 12 px; возвращает и направляющие.
- `overlaps(rect, zones)` — пересечения и выход за край.
- `chromeOnScreen(measured, screen)` — геометрия интерфейса Foundry ГМа, перенесённая на экран игрока для
  предпросмотра: левые зоны прижаты влево, хотбар — по центру снизу, сайдбар — справа.

## Зоны интерфейса Foundry

- Меряются вживую как объединение видимых пунктов, а не контейнеров: контейнеры `#scene-controls` и
  `#scene-navigation` растянуты на всю колонку, хотя кнопок в них меньше (проверено на 14.367).
- Сплошные зоны: контролы сцены (`li`), навигация сцен (`li`), игроки, хотбар, вкладки сайдбара и раскрытый сайдбар.
- Пунктиром — уведомления и календарь dnd5e, если они видны.
- Carousel Combat Tracker — если модуль активен. Его id сверяется при реализации, в мире `test` он не
  установлен.

## Живая проверка

1. Фон ошибок; раскладка этапа 2 сохраняется: блоки на прежних местах.
2. Вход в режим из панели. Перетаскивание обоих блоков, направляющие, якорь по отпусканию. Отступы в панели.
3. «Сохранить»: у игрока блоки встают туда же. Смена `uiScale` и разрешения окна — у того же якоря.
4. Направления: вниз, вверх, в ряд. «Видно карточек» = 3 → «+N».
5. Слой «Сцена»: переопределение одного блока, на другой сцене — мировое; «Сбросить к миру».
6. Перекрытия: блок поверх хотбара и за краем экрана подсвечен, список в панели.
7. Предпросмотр 1366×768 и 3440×1440.
8. Игрок сворачивает колонку элиты и полосу; выключенное «сворачивать» убирает кнопки.
9. Клавиатура: стрелки двигают выбранный блок, Escape выходит из режима.

## Решения (2026-10-26, «Всё да»)

1. Размещение — чистый CSS (доля якоря + отступ × `uiScale`, сдвиг на свой размер); `ResizeObserver` только в
   режиме раскладки.
2. По умолчанию: боссы `tc` 0/16 вниз; элита `ml` 104/0 вниз, 12 карточек; «сворачивать» у обоих.
3. Правки — черновик: на экране ГМа сразу, в мир — по «Сохранить»; «Отмена» и закрытие откатывают (с вопросом).
4. Пустой блок в режиме раскладки — заглушка обычного размера с названием.
5. Предпросмотр — мини-карта в панели; на экране ГМа — настоящие перекрытия по живым замерам.
6. Направления: «вниз», «вверх» (растёт вверх, первый у якоря), «в ряд» — только у боссов.
7. Колонка элиты сворачивается у игрока в плашку «Элита · N ▸» (по сцене, клиентская настройка); пункт
   «Игроки могут сворачивать» уходит из настроек модуля, значение переносится в блок боссов.
8. Слой «Сцена» переопределяет тронутый блок целиком, «Сбросить к миру»; раскладку пишет любой ГМ напрямую.
9. Стрелки — 1 px, Shift — 10 px; Escape или «Готово» — выход; вход — кнопкой в панели «Активные боссы».
10. Проверка по 9 шагам; один коммит, push по слову пользователя.
