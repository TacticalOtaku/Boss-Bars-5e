## Результат (версия 0.5.0)

- **Автопоказ.** Когда бой переходит в раунд 1, активный ГМ показывает участников с автопоказом в профиле. В конце
  боя и при поражении он скрывает их с задержкой. Всё это по профилю, для боссов и элиты.
- **Статусы** на полосе босса и на карточке элиты (если ранг разрешает):
  - иконки активных эффектов, как на токене;
  - служебные статусы Midi и дубли DAE не показываются никогда;
  - ГМ скрывает лишнее в профиле;
  - у боссов есть свои статусы, ГМ включает их из панели.
- **Мини-полосы** под полосой босса и на карточке элиты (если ранг показывает заливку). Источники:
  - временные ХП;
  - легендарные действия и сопротивления;
  - заряды предмета;
  - числовое поле по пути;
  - ручной счётчик ГМа.

  У каждой мини-полосы есть галочка «видна игрокам».
- **Щит временных ХП** поверх заливки.
- **Редактор профиля** получает вкладки «Мини-полосы», «Статусы» и «Автопоказ». В панели появляются ручные счётчики
  и свои статусы.

Не входит в этап: стиль статусов и мини-полос как пресеты (этап 5), эффекты урона (этап 5), фазы (6).

## Данные

Новые поля **необязательные**. Читатели 0.4.0 сохраняют неизвестные ключи, поэтому версии схем не растут: правило —
поднимать версию, только когда старый читатель исказит или выбросит новые данные.

**Профиль** (оба вида, кроме пометок):

```ts
autoShow: { onCombatStart: boolean; hideOnCombatEnd: boolean; hideOnDefeat: boolean; delay: number /* с */ }
statuses: { hidden: string[] /* id состояний и имена эффектов */; custom?: CustomStatus[] /* только босс */ }
miniBars: MiniBar[] /* до 6 */
CustomStatus = { id; name; img; description /* ≤ 200, текст */ }
MiniBar = { id; label; view: "bar" | "pips"; players: boolean;
            source: { type: "temp" } | { type: "legact" } | { type: "legres" } | { type: "item"; itemId }
                  | { type: "path"; path; max: number | string /* число или путь */ } | { type: "counter"; max } }
```

**Экземпляр** (флаг сцены):

```ts
counters?: Record<miniBarId, number>   customStatuses?: string[] /* включённые свои статусы */
```

Пишет только активный ГМ: новые действия `setCounter` и `toggleStatus`, их полезная нагрузка проверяется
`parseAction`.

## Поведение

### Автопоказ и автоскрытие (только активный ГМ)

- **Начало боя:**
  - `updateCombat` с переходом раунда 0 → 1;
  - участники берутся из боя по `combatant.sceneId` + `tokenId` (не из `game.combat`: он у каждого клиента свой);
  - показ идёт по режиму профиля, тем же путём, что `show`.
- **Конец боя.** На `deleteCombat` и по прошествии задержки скрываются экземпляры участников с «скрыть в конце боя».
- **Поражение.**
  - Когда экземпляр впервые становится поверженным, через задержку активный ГМ перепроверяет его и скрывает, если
    тот всё ещё повержен.
  - Повод любой из трёх: 0 ХП, статус `dead`, отметка «повержен» в трекере. Все три Midi может ставить при
    «Полной автоматизации».
  - Экземпляр «×N» повержен, только когда повержены все его токены.
- Таймеры живут у активного ГМа. F5 их теряет. Повторная проверка при старте — пройти по поверженным экземплярам и
  скрыть тех, у кого «скрыть при поражении».

### Статусы (каждый клиент сам, по данным актёра)

- **Источник** тот же, что у иконок токена Foundry 14: `actor.appliedEffects` с `showIcon` ALWAYS, или CONDITIONAL
  и `isTemporary`. Так ГМ видит на полосе ровно то, что на токене. У игрока dnd5e прячет «Окровавлен»
  (`isConcealed`) — он не увидит его и здесь.
- **Не показываются никогда:**
  - статусы Midi `reaction`, `bonusaction`, `flanking`, `flanked`;
  - эффекты с `flags.dae.autoCreated` — дубли зависимых состояний DAE.
- **Стаки DAE:** число из `flags.dae.stacks` выводится значком на иконке.
- **Скрытые в профиле** — по id состояния и по имени эффекта.
- **Подсказка:** имя, описание как текст (HTML вырезается) и оставшееся время из `duration.label` Foundry.
- **Видно максимум:** у полосы 10, у карточки 4, остальное — «+N». Пресет стиля статусов придёт на этапе 5.
- **Свои статусы босса** идут после эффектов, в порядке профиля.
- **Пересчёт:** подавление эффекта не всегда даёт событие эффекта (истечение, предмет снят), поэтому статусы
  пересчитываются на тех же хуках `updateActor`, `updateItem` и хуках эффектов, что и ХП. Заодно добавляется
  `updateWorldTime` — для истечения по времени.

### Мини-полосы

- **Значения:**
  - временные ХП — `hp.temp`, максимум — самое большое значение с тех пор, как щит появился (у dnd5e нет максимума
    временных ХП; `hp.tempmax` — это поправка к максимуму ХП, не он);
  - легендарные действия и сопротивления — `resources.legact` / `legres` (`value` / `max`);
  - заряды — `item.system.uses` (`value` / `max`);
  - поле — `getProperty(actor, path)`, путь только `system.…` из `[A-Za-z0-9_.]`;
  - счётчик — значение в экземпляре, максимум в профиле.
- **Вид:**
  - «полоса» или «ромбики»; у легендарных по умолчанию ромбики, ромбиков не больше 10, дальше — полоса;
  - ГМ видит числа;
  - игрок видит полосу или ромбики без чисел и только мини-полосы с «видна игрокам».
- В режиме «×N» значения складываются по токенам, как ХП.
- У элиты мини-полосы видны, только если ранг показывает заливку.

### Щит временных ХП

Голубой отрезок сразу за заливкой, шириной `temp / effectiveMax`, обрезан краем полосы. Игрок видит его без чисел.
На этапе 5 его включение переедет в пресет заливки.

## Живая проверка (мир `test`, ГМ + игрок)

1. Фон ошибок; полосы этапов 1–3 на месте.
2. Профиль: вкладки, мини-полосы всех 6 источников, скрытый статус, свой статус, автопоказ.
3. Бой: «Начать» → в раунде 1 показаны участники с автопоказом; конец боя → скрыты через задержку.
4. Поражение тремя путями → скрытие через задержку; лечение до задержки отменяет скрытие.
5. Статусы: состояние с HUD токена, эффект с длительностью (подсказка с раундами), скрытый не виден, свой статус
   из панели; у игрока — без «Окровавлен», если dnd5e его прячет.
6. Мини-полосы: легендарные тратятся, заряд предмета, поле, счётчик ±; игрок не видит чисел и скрытых полос.
7. Щит: `hp.temp` > 0.
8. **Midi и DAE на «Полной автоматизации»:** атака с автоприменением урона, эффект с зависимым состоянием (без дубля),
   стак, «мёртв» от Midi → скрытие.
9. Регрессия этапов 2–3: элита, «×N», раскладка.

## Решения (2026-10-26, «Всё да»)

1. Автопоказ по умолчанию: «показывать в начале боя» выключено, «скрыть в конце боя» и «скрыть при поражении»
   включены, задержка 3 с (0–60); одинаково для боссов и элиты.
2. Начало боя — переход раунда 0 → 1 в `updateCombat` у активного ГМа; участники по `combatant.sceneId` + `tokenId`.
3. Поражение: через задержку активный ГМ перепроверяет экземпляр, вылеченный не скрывается; при старте ГМ скрывает
   уже поверженных с «скрыть при поражении».
4. Статусы — как иконки токена Foundry 14 (`appliedEffects`, `showIcon` ALWAYS или CONDITIONAL + `isTemporary`);
   Midi `reaction`/`bonusaction`/`flanking`/`flanked` и `flags.dae.autoCreated` скрыты всегда; стак DAE значком;
   «Окровавлен» игрок не видит, если dnd5e его прячет.
5. Скрытие в профиле: галочки по id состояния и имена эффектов (по одному на строку).
6. Свои статусы только у боссов: в профиле (иконка, имя, описание ≤ 200), включаются у экземпляра из панели.
7. Подсказка: имя, описание текстом, `duration.label`; лимит 10 на полосе, 4 на карточке, остальное «+N»; иконки
   принимают курсор.
8. Мини-полосы: до 6 на профиль; подпись, вид «полоса / ромбики» (легендарные — ромбики), «видна игрокам» (вкл.);
   путь только `system.` из `[A-Za-z0-9_.]`, максимум — число или путь; ГМ видит числа, игрок нет; в «×N» сумма.
9. Щит временных ХП всегда включён: голубой отрезок `temp / max` за заливкой, у игрока без чисел.
10. Живая проверка шага 8 на «Полной автоматизации» Midi в `test` — согласие получено; настройки сохранить и вернуть.
    Один коммит в конце, push по слову пользователя.
